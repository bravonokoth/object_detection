# object_detection

A full-stack web app for real-time object detection using YOLOv8. Upload any image and get instant detections for 80+ classes (people, vehicles, animals, etc.).

## 🚀 Live Demo
.[https://objectdetection-vgxwkbppwshttd5meyswl5.streamlit.app]

## Features
- Image upload & real-time YOLOv8 inference
- Bounding boxes, labels, and confidence scores
- Side-by-side before/after view
- Download annotated results
- No training needed – uses pre-trained model

## Tech Stack
- **AI Model**: YOLOv8 (Ultralytics) – State-of-the-art object detection
- **Frontend/Backend**: Streamlit (Python-based web framework)
- **Image Processing**: Pillow, OpenCV
- **Deployment**: Streamlit Cloud (free & instant)

## How to Run Locally
1. Clone the repo: `git clone https://github.com/bravonokoth/object_detection.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `streamlit run app.py`
4. Open the local URL in your browser

## Deployment
- Deployed to [Streamlit Cloud](https://streamlit.io/cloud) for free hosting.
